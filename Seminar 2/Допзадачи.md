# Семинар 2. Дополнительные задачи

Все задачи — для самостоятельной работы. Код пишем на C, компилируем с
`-Wall -Wextra -Werror`. Отдельно соберите с санитайзерами (флаг `-fsanitize`),
рекомендую попробовать `address`, `undefined`, `memory`.

## Задача 1. Словарь

Прочитайте текстовый файл целиком в память: число строк и их длина заранее
неизвестны. Поддержите следующую функциональность (для сдачи необязательно
приносить всё, но и оценка будет ниже):

1. **Отсортировать строки** — используйте и стандартную функцию `qsort`, и свою сортировку.
2. **Сортировать с учётом регистра и без** — после сортировки без учёта регистра
   `Apple` и `apple` оказываются рядом.
3. **Сортировать с конца строки** — строки сравниваются справа налево, рифмы
   оказываются рядом.
4. **Поиск по строкам** — точный поиск слова в отсортированном массиве.
5. **Поиск по префиксу** — ввели `ap` → напечатать все строки, начинающиеся с `ap`.
6. **Русский текст** — UTF-8 (если работаете на Linux, macOS или WSL), CP1251 (Windows).

Попробуйте на стихотворениях русской классики.

**Подсказка.** Используйте `malloc` и `free` для памяти, `fopen` и
`fread` для файлов. В языке C строки — массив `char`.
